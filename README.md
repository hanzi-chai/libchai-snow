# 汉字编码算法・冰雪拼音特化

## 准备文件

首先拉取手指分布和当量文件：

```bash
make fetch
```

各方案的配置文件和元素序列文件放在对应的项目目录下：

- `project-feihua/`：冰雪飞花
- `project-snow2/`：冰雪二拼
- `project-qingyun/`：冰雪清韵

## 运行

各方案的 Makefile 目标前缀：

| 方案 | 调试编码 | 发布编码 | 单线程优化 | 多线程优化（10 线程）|
|------|----------|----------|------------|------------|
| 冰雪飞花 | `fed` | `fe` | `fo` | `fp` |
| 冰雪二拼 | `s2d` | `s2e` | `s2o` | `s2p` |
| 冰雪清韵 | `qyd` | `qye` | `qyo` | `qyp` |

例如，对冰雪飞花方案进行多线程优化：

```bash
make fp
```

多线程运行时，各线程进度日志写入 `output-<时间戳>/<线程序号>/log.txt`，汇总写入 `output-<时间戳>/总结.txt`。
